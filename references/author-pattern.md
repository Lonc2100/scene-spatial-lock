# 作者两段范例的适配原则

作者原图为2026-11-02的“空间锁：同一清晨，同一老屋……”及“摄影机轴线锁：卧室轴线为‘床—窗—书桌’……”截图。完整原件留在作品，不把私人素材复制进Skill。

保留的机制：同一地点与时段；逐区域陈设；相邻关系和连通路线；人物走位；晨光/画外事件方向；不可读特殊标记；各区域具体轴线；不越轴；硬切只换观察角度而不重置角色和道具状态。

轴线限制服从本例实际设定：同侧叙事沿明确一侧；已给定正反面并明确要求反向机位时，写清两端视点及切镜状态，不机械套“禁止反打”。本期书房中人物为李白，不能沿用旧无人版本。未提供人物信息时保留未知，不能把“没写人物”推成“无人”。

参考机位的画面左右可以用来介绍母图，换机位时不能把它误读成永远固定屏幕左右。没有人物/事件/特殊标记的场景明确不适用，不为凑格式发明角色、爆炸或符号。

与environment-look-lock的区别：后者管环境制作、光色合同和美术审核；本Skill产物是可直接放进跨镜头生成中的空间/轴线正文。两者可配合，但不能互相冒名。
